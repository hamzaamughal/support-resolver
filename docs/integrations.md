# Integrations & Data

## Available integrations
Beacon connects with Slack, GitHub, and Google Calendar out of the box. Set them up under Settings → Integrations. Each integration uses OAuth, so you authorize it once and can revoke access anytime from the same screen.

## Slack notifications
After connecting Slack, choose which events post to which channel (project updates, mentions, due-date reminders). Notifications are per-project, configured under a project's Settings → Notifications.

## Export your data
You can export all your projects and tasks as JSON or CSV from Settings → Data → Export. Exports are generated on demand and emailed to you as a download link within a few minutes.

## API access
Pro and Business plans include REST API access. Generate an API key under Settings → Developer. Rate limits are 1,000 requests/hour on Pro and 5,000/hour on Business.
